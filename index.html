📲 Pasang Aplikasi JejakKarbonKu

Pasang JejakKarbonKu GGF di layar utama ponsel (Android / iPhone) atau komputer Anda untuk akses cepat, tampilan layar penuh tanpa URL bar, dan dapat digunakan secara offline.

⚡ Pasang Otomatis di Android:
Cara Manual di Google Chrome / Browser Android:
1. Ketuk ikon menu titik tiga (⋮) di pojok kanan atas browser.
2. Pilih "Tambahkan ke Layar Utama" (Add to Home screen) atau "Instal Aplikasi".
3. Ketuk Instal / Tambahkan. Ikon JejakKarbonKu akan muncul di beranda HP Anda.
🍎 Cara Pasang di iPhone / iPad (Safari):
1 Buka link di browser Safari, lalu ketuk tombol Bagikan (Share) ⎋ di bilah bawah layar.
2 Gulir ke bawah pada menu, lalu pilih opsi "Tambah ke Layar Utama" (Add to Home Screen) ➕.
3 Ketuk "Tambah" (Add) di sudut kanan atas. Aplikasi JejakKarbonKu akan tersimpan seperti aplikasi App Store!
💻 Pasang di Komputer / Laptop (Windows, macOS, Linux):
Melalui Bilah Alamat (Chrome / Edge / Brave):
1. Klik ikon 📥 Install / Pasang Aplikasi di sebelah kanan bilah URL browser Anda.
2. Klik tombol Install.
3. JejakKarbonKu akan terbuka di jendela tersendiri dan ikon shortcut akan tersedia di Desktop / Start Menu.
